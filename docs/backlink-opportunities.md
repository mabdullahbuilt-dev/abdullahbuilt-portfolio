## Priority

1. Update owned GitHub profiles/repositories.
2. Publish two original technical articles tied to public source.
3. Launch the strongest relevant product on Product Hunt, DevHunt, or Indie Hackers.
4. Submit the portfolio to a small number of selective design galleries.
5. Build community links through useful technical contributions rather than directory volume.
